# CipherSchools Flutter Assignment

This is a basic **Expense Tracking Application** built using **Flutter** and **Firebase**, created as part of the CipherSchools Flutter Assignment.

---

## 🚀 Features

- 📥 Add income and expense entries
- 🧾 Categorize expenses (Food, Travel, Subscriptions, Shopping)
- 🧹 Delete expenses using swipe gestures
- 📊 View total income and total expenses
- 🗃️ Local storage using Hive
- 🔐 Google Sign-In using Firebase Authentication
- ☁️ Cloud Firestore to store user information
- 🔄 Persistent login using Shared Preferences

---

## 🔥 Bonus Feature

- 🧠 **Expense Chart**: Visualize your expenses by category using a pie chart for quick analysis.

---

## 📦 Tech Stack

- Flutter
- Dart
- Firebase Auth
- Cloud Firestore
- Hive (local storage)
- Provider (state management)
- Shared Preferences
